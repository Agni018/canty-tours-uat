# Canty Tours
Responsive static India travel website. Business contact: +91 89216 11825, supplied by the owner.

## Run
node preview.mjs
Open http://127.0.0.1:4173

## Content
Journey routes are illustrative, with prices on request. No testimonials, performance claims or rates are fabricated. All quotes and bookings are handled directly via WhatsApp. This is a new private Sites deployment and does not modify cantytours.com DNS or existing hosting.

## Competitor comparison
- Thomas Cook https://www.thomascook.in/holidays/ : destination and traveller-interest browsing. Applied as region and style filters.
- SOTC https://www.sotc.in/holidays : custom holiday enquiry. Applied as a compact WhatsApp trip planner.
- Thrillophilia https://www.thrillophilia.com/countries/india/tours : scannable journey offerings. Applied as duration, route, itinerary and side-by-side comparison.
Original layout and copy; no competitor branding or proprietary content copied. Checked 11 October 2026.
