# Canty Tours
Responsive static travel website with Kerala as the main focus and journeys across India. Business contact: +91 89216 11825, supplied by the owner.

## Run
Open `index.html` directly, or use Node.js for a local HTTP preview:

```sh
node preview.mjs
```

Open http://127.0.0.1:4173. No dependencies or build step are required.

## Content
Day-by-day sample itineraries cover every destination in the photo dropdown. Their routes and key activities were checked against published Paradise Holidays itineraries on 19 October 2026 and condensed into original summaries. Each journey has a direct reference link; the complete mapping is in [itinerary sources](assets/itinerary-sources.md). Kerala remains the default collection, including routes that combine Kerala and Tamil Nadu. The All India collection and Beyond Kerala section retain Rajasthan, Goa, Ladakh, Sikkim and the Golden Triangle.

Filter by destination, style and duration, compare up to three journeys, and personalise a route in the WhatsApp planner. The planner includes trip length and occasion. It prepares a message for the visitor to review and send; no form details are stored and no booking is made on the site.

The “Where to?” dropdown includes a responsive photo grid for Guruvayoor, Athirapilly, Munnar, Thekkady, Vagamon, Houseboat, Alleppey, Kumarakom, Marari, Kollam, Varkala, Kovalam, Kanyakumari, Madurai, Rameswaram and Wayanad. Names appear beneath each photo. Regional options remain available beneath the grid. Keyboard users can use Tab or arrow keys to browse and Escape to close. Alleppey matches Alappuzha routes; Houseboat includes overnight and daytime houseboat itineraries. All 16 choices have matching routes before style and duration filters are applied. If a combination of filters has no match, visitors can request a custom trip. Routes through Kanyakumari, Madurai and Rameswaram appear in both Kerala and South India collections.

Routes are illustrative, with prices on request. No testimonials, performance claims, accreditation or rates are fabricated. All quotes and bookings are handled directly with Canty Tours. These are local source updates; deployment and existing hosting are unchanged.
